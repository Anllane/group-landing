**ALANE GROUP** — это современный, высококонверсионный Landing Page для строительной компании, специализирующейся на монтаже и ремонте плоской и скатной кровли.

---

## ✨ Особенности проекта

*   **📱 Mobile-First дизайн:** Идеальное отображение на любых устройствах, от смартфонов до широкоформатных мониторов.
*   **🧮 Интерактивный калькулятор:** Встроенный калькулятор стоимости с динамической сменой изображений в зависимости от выбранного материала и формы крыши.
*   **⚡ Высокая производительность:** Чистый код (Vanilla JS + CSS3), отсутствие тяжелых фреймворков и отложенная загрузка ресурсов (lazy loading).
*   **🎨 Современный UI/UX:** Продуманная типографика, плавная анимация (micro-interactions) и удобные плавающие виджеты для мгновенной связи.
*   **🔍 SEO Оптимизация:** Семантическая верстка, правильная иерархия заголовков, мета-теги и атрибуты доступности.

---

## 🛠️ Технологический стек

*   **HTML5** — семантическая структура страницы.
*   **CSS3** — кастомные свойства (CSS Variables), Grid & Flexbox, медиазапросы.
*   **Vanilla JavaScript** — логика калькулятора, управление DOM и интерактивность, без сторонних зависимостей.

---

## 🚀 Как запустить локально

Проект полностью статичный, для запуска не требуется установка npm-пакетов.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Anllane/group-landing.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd group-landing
   ```
3. Откройте файл `index.html` в любом браузере или используйте расширение **Live Server** в VS Code для автоматического обновления страницы.
